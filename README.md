# Kivorly - Super App for Bangladesh 🇧🇩

**Kivorly** is a next-generation iOS Super App built natively with SwiftUI, designed specifically for Bangladesh. It integrates 8 essential lifestyle, mobility, and commerce verticals into a unified, fluid experience with transparent pricing strictly in Bangladeshi Taka (`৳`) and local payment methods (**bKash**, **Nagad**, and **Cash on Delivery**).

---

## Key Highlights

- **Native SwiftUI Architecture**: Declarative, high-performance UI running smoothly on iOS 17+.
- **Authentic Bangladeshi Experience**: Tailored for Dhaka and all 64 districts across 8 administrative divisions.
- **Local Currency & Payment Gateways**: All pricing strictly formatted in Bangladeshi Taka (`৳`), featuring seamless integration for bKash, Nagad, and Cash on Delivery (COD).
- **Default Profile**: Pre-configured for **MD Shoaib Khan** with custom 3D avatar integration.
- **Refined Typography**: Clean title-cased and sentence-cased typography throughout the app with no harsh uppercase labels.
- **Dynamic Island & Live Activities**: Interactive banners for ongoing rides, deliveries, and bookings.

1. **Clone the repository**:
   ```bash
   git clone <repository-url>
   cd "Untitled Project"
   ```

2. **Open in Xcode**:
   ```bash
   open "Untitled Project.xcodeproj"
   ```

3. **Select Run Destination**:
   - Choose any iOS 17+ Simulator (e.g., iPhone 15, iPhone 16, or iPhone 17).

4. **Build and Run**:
   - Press `Cmd + R` or click the **Play** button in Xcode.

## Design Guidelines

- **Currency Consistency**: All prices must be formatted in Bangladeshi Taka using the `৳` symbol.
- **Typography Case**: Maintain clean sentence-casing or title-casing. Avoid forced uppercase strings.
- **Single-Line Badges**: Badge lists should reside on horizontal scroll containers to avoid awkward vertical wrapping.
- **Performance**: Use native SwiftUI layout primitives and SF Symbols wherever possible for fluid 120Hz ProMotion responsiveness.
