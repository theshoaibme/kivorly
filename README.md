## ⚡ Core Verticals & Capabilities

| Vertical | Features & Details |
| :--- | :--- |
| 🚗 **Ride Sharing** | Interactive Uber-style Dhaka map, pickup/drop-off pins, vehicle tiers (Moto, Car, CNG, Micro), real-time pricing, and fare estimate breakdown. |
| 🍔 **Food Delivery** | Authentic high-resolution stock photography (no generic icons or emojis), Dhaka culinary icons (Sultan's Dine, Madchef, The Pizza Guy, North End), dish itemization, and checkout. |
| 🥬 **Fresh Bazaar** | 2x2 grid format, real grocery photos (Ilish fish, Miniket rice, mustard oil, farm eggs, beef cuts), instant category filtering, and cart counter. |
| 🛍️ **Brand Mall** | Clean shopping bag view, soft background, flat design with zero gradients and zero drop shadows, default iOS button styling, and instant checkout. |
| 🎫 **Tickets & Travel** | Scania AC bus, Bangladesh Railway train, and Barisal luxury launch bookings across all 64 districts. |
| 📦 **Express Parcels** | Doorstep parcel pickup, nationwide delivery network, weight selector, and Cash on Delivery (COD) settlement. |
| 🏖️ **Hotels & Stays** | Handpicked resorts in Cox's Bazar, Sylhet tea estates, Dhaka luxury escapes, with date pickers and guest selectors. |
| 🛠️ **Home Services** | Certified technicians for AC servicing, home cleaning, plumbing, electrical maintenance, and home appliance repairs. |
